## 🚀 Getting Started

To view the portfolio locally:

1. Clone the repository:

   ```bash
   git clone https://github.com/sourav444-tec/SUBHANKAR_DAS-PORTFOLIO.git
   cd SUBHANKAR_DAS-PORTFOLIO
   ```

2. Open `index.html` in your web browser or use a local server:

   ```bash
   # Using Python
   python -m http.server 8000

   # Using Node.js (http-server)
   npx http-server
   ```

3. Navigate to `http://localhost:8000` (or specified port)
